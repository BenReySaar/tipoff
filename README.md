# טיפ-אוף · מדריך העלאה לאוויר

המדריך הזה לוקח אותך מהתיקייה הזו לאפליקציה חיה שהורים פותחים בטלפון, עם התראות, יומן מתעדכן ודף נתוני שימוש.
לא צריך ידע בתכנות, רק להעתיק פקודות. בפעם הראשונה זה לוקח בערך 45 דקות.

---

## מה יש בתיקייה

| קובץ / תיקייה | מה זה |
|---|---|
| `public/` | האפליקציה עצמה: מה שההורה רואה בטלפון |
| `src/` | השרת: מושך את הלוח מהאיגוד כל שעה, מזהה שינויים, שולח התראות, יומן ונתוני שימוש |
| `schema.sql` | מבנה מסד הנתונים |
| `wrangler.toml` | הגדרות. יש בו 5 מקומות שכתוב בהם `FILL` ותמלאי אותם לפי המדריך |
| `tools/browser-sync.js` | תוכנית ב׳ אם אתר האיגוד חוסם את השרת (סעיף 8) |
| `public/privacy.html`, `public/accessibility.html` | טיוטות של מדיניות פרטיות והצהרת נגישות. צריך למלא בהן את החלקים בסוגריים מרובעים |

## כמה זה עולה

| מה | מחיר |
|---|---|
| Cloudflare Workers Paid | 5 דולר לחודש (כ־19 ₪). הכרחי: בתוכנית החינמית שרת יכול לבצע רק 50 בקשות בכל ריצה, והסנכרון צריך כ־160 |
| כתובת משלך (לא חובה בהתחלה) | כ־60–100 ₪ לשנה ל־‎.co.il |

עד עשרות אלפי משתמשים זה המחיר. מעבר לזה Cloudflare גובה תוספת קטנה לפי שימוש.

---

## 1. מה צריך לפני שמתחילים

1. **Node.js**: מורידים ומתקינים מ־https://nodejs.org (הגרסה שמסומנת LTS).
2. **חשבון Cloudflare**: נרשמים ב־https://dash.cloudflare.com/sign-up.
3. **מעבר לתוכנית Workers Paid**: בלוח הבקרה של Cloudflare ← Workers & Pages ← Plans ← Workers Paid. צריך כרטיס אשראי.

## 2. פותחים חלון פקודות בתיקייה

- **מק:** פותחים את Terminal, כותבים `cd ` (עם רווח), גוררים את תיקיית `tipoff` לחלון ולוחצים Enter.
- **ווינדוס:** פותחים את התיקייה, לוחצים בשורת הכתובת למעלה, כותבים `powershell` ולוחצים Enter.

מכאן, כל פקודה במדריך מעתיקים לחלון ולוחצים Enter.

## 3. התקנה וחיבור ל־Cloudflare

```
npm install
npx wrangler login
```
ייפתח דפדפן. מאשרים את הגישה וחוזרים לחלון הפקודות.

## 4. יוצרים את מסד הנתונים ואת האחסון

```
npx wrangler d1 create tipoff
```
הפקודה מדפיסה שורה עם `database_id = "..."`. מעתיקים את הערך לקובץ `wrangler.toml`, במקום `FILL-d1-database-id`.

```
npx wrangler kv namespace create KV
```
הפקודה מדפיסה `id = "..."`. מעתיקים אותו במקום `FILL-kv-namespace-id`.

ויוצרים את הטבלאות:
```
npm run db:init
```

## 5. מפתחות להתראות ולדף הנתונים

```
npm run vapid
```
הפקודה מדפיסה שני דברים:
1. שורה שמתחילה ב־`VAPID_PUBLIC =`. מעתיקים אותה ל־`wrangler.toml` במקום השורה הקיימת.
2. ערך ארוך שמתחיל ב־`{"kty":"EC"...`. מריצים את הפקודה הבאה, ומדביקים אותו כשהיא שואלת:
```
npx wrangler secret put VAPID_PRIVATE_JWK
```

עכשיו בוחרים **סיסמה ארוכה** (לפחות 20 תווים) לדף נתוני השימוש, ושומרים אותה במקום בטוח:
```
npx wrangler secret put ADMIN_KEY
```

ב־`wrangler.toml` מחליפים גם את `FILL-your-email` באימייל שלך. Apple ו־Google דורשות כתובת ליצירת קשר בהתראות.

## 6. העלאה

```
npm run deploy
```
בסוף מופיעה כתובת כמו `https://tipoff.<השם-שלך>.workers.dev`. **זו כתובת האפליקציה.**
מעתיקים אותה ל־`APP_URL` ב־`wrangler.toml` ומריצים שוב `npm run deploy`.

## 7. הסנכרון הראשון ובדיקה

השרת מושך את הלוח מאתר האיגוד אוטומטית בכל שעה, בדקה 7. אחרי הריצה הראשונה:

1. פותחים בדפדפן: `https://<הכתובת שלך>/stats?key=<הסיסמה מסעיף 5>`
2. בתחתית הדף, תחת **סנכרון מול אתר האיגוד**, צריך להופיע **תקין** ומספר המשחקים (כ־15,000).
3. פותחים את הכתובת בטלפון, בוחרים קבוצה, מוסיפים למסך הבית, ובמסך **התראות** לוחצים **הפעלת התראות** ואז **שליחת התראת בדיקה**.

## 8. אם הסנכרון נכשל (תוכנית ב׳)

אם בדף הנתונים מופיע **נכשל** ו"אתר האיגוד חסם את השרת", אפשר לשלוח את הנתונים מהדפדפן שלך, כמו שעשינו בפעם הראשונה:

1. פותחים את `tools/browser-sync.js` ומחליפים בו את שתי השורות העליונות: הכתובת שלך והסיסמה.
2. פותחים את https://ibasketball.co.il בכרום, לוחצים F12 ← Console.
3. מדביקים את כל הקובץ ולוחצים Enter. תוך כדקה תופיע הודעה עם מספר המשחקים.

כל ההתראות על שינויים עובדות גם בדרך הזו. החיסרון: זה קורה רק כשמריצים את הסקריפט, ולא כל שעה. אם זה המצב לאורך זמן, זה הזמן לפנות לאיגוד.

## 9. כתובת משלך (כשמוכנים)

1. קונים כתובת ‎.co.il אצל רשם ישראלי (למשל LiveDNS, Box, domainthenet).
2. ב־Cloudflare: **Add a domain**, ומעדכנים אצל הרשם את שרתי ה־DNS לאלה ש־Cloudflare נותנת.
3. ב־Workers & Pages ← tipoff ← Settings ← **Domains & Routes** ← Add ← Custom domain.
4. מעדכנים את `APP_URL` ב־`wrangler.toml` ומריצים `npm run deploy`.

שימו לב: מי שכבר הוסיף את האפליקציה למסך הבית מהכתובת הקודמת יצטרך להוסיף אותה שוב. לכן עדיף לעבור לכתובת משלך לפני שמפיצים להרבה הורים.

## איך יודעים כמה אנשים משתמשים

דף הנתונים: `https://<הכתובת שלך>/stats?key=<הסיסמה>`. כדאי לשמור אותו כסימנייה.

| מה רואים | מה זה אומר |
|---|---|
| **פעילים היום / ב־7 ימים / ב־30 ימים** | כמה מכשירים פתחו את האפליקציה |
| **מכשירים בסך הכל** ו**עם קבוצה לפחות** | כמה הגיעו, וכמה באמת בחרו קבוצה |
| **התראות פעילות** | המדד הכי חשוב: מי שהפעיל התראות קיבל ערך אמיתי |
| **הוסיפו למסך הבית** | מי שהתקין את האפליקציה |
| **חוזרים** | מכשירים מלפני שבוע ויותר שנכנסו שוב השבוע |
| **מה עושים באפליקציה** | ניווטים, שיתופים, חיבור יומן ועוד |
| **התראות** ו**שינויים שזוהו** | כמה שינויים בלוח השרת תפס, וכמה התראות יצאו |
| **הקבוצות והמועדונים הכי נעקבים** | איפה האפליקציה תפסה, ולאיזה מועדון כדאי לפנות |

"משתמש" הוא מכשיר. הורה עם טלפון ומחשב נספר פעמיים. השרת לא שומר שמות, טלפונים או אימיילים, רק מזהה אקראי שנוצר בטלפון.

## עדכונים שגרתיים

- **עונה חדשה (פעם בשנה, באוגוסט–ספטמבר):** משנים את `SEASON = "2026"` ל־`"2027"` ב־`wrangler.toml` ומריצים `npm run deploy`.
- **חשבונות ברשתות החברתיות:** ב־`public/index.html` מחפשים `const SOCIAL=` ומכניסים את הקישורים, למשל `['אינסטגרם','https://instagram.com/...']`. ואז `npm run deploy`.
- **כל שינוי בקוד:** שומרים את הקובץ ומריצים `npm run deploy`.
